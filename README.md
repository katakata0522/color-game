# 色の見え方体験ゲーム v5.1

色の違いを見分けるブラウザゲームです。  
楽しいゲーム体験を第一にしつつ、色の見え方の多様性を自然に感じてもらうことを目的としています。

## 重要な注意

このコンテンツは**娯楽・体験用**です。

- 医療上の検査、診断、判定、スクリーニングには使用できません
- ゲームの正誤やスコアから、色覚特性の有無を判断できません
- 画面の色域、輝度、ブルーライト設定、周囲の照明、視聴距離、疲労などで結果が変わります
- 日常生活で色の見分けに継続的な困りごとがある場合は、ゲーム結果ではなく眼科などの医療機関へ相談してください

## ハイブリッドの考え方

- **表**：色の違いを見分ける爽快なゲーム
- **裏**：潜在的に色の見え方で困っている可能性のある人に、優しく医療機関への相談を促す
- お子さんが遊んだ場合は「大人の家族に内容を見てもらってください」という導線を用意しています

診断的な表現は一切使いません。

## 主な機能（v5.1）

- 15問の色見分けゲーム
- 連続正解コンボボーナス
- 通常・プロタン・デュータン・トリタンの簡易表示切替
- 強調体験モード
- 改善された問題生成（色相＋明度、最低色差保証）
- キーボード操作
- 効果音ON／OFF
- OS設定へ追従するライト／ダークモード
- 終了時の家族導線（子供が遊んだ場合の配慮）

## 保存データ

テーマ設定だけをlocalStorageへ保存します。

- キー: `colorGameTheme`
- 値: `light`または`dark`

## テスト

```bash
node --check script.js
node --check theme-safety.js
node tests/static-check.cjs
```

## 色表示の限界

`script.js`内の色変換行列と序盤ステージの色は、ブラウザ上で違いを簡易的に体験するための近似です。個人ごとの見え方を再現するものではなく、医療機器や標準化された色覚検査の代替ではありません。
