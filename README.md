# 色の見え方体験ゲーム v5.2

色の違いを見分けるブラウザゲームです。  
楽しいゲーム体験を第一にしつつ、色の見え方の多様性を自然に感じてもらうことを目的としています。

## 重要な注意

このコンテンツは**娯楽・体験用**です。

- 医療上の検査、診断、判定、スクリーニングには使用できません
- ゲームの正誤やスコアから、色覚特性の有無を判断できません
- 画面の色域、輝度、ブルーライト設定、周囲の照明、視聴距離、疲労などで結果が変わります
- 日常生活で色の見分けに継続的な困りごとがある場合は、ゲーム結果ではなく眼科などの医療機関へ相談してください

## ハイブリッドの考え方

- **表**：色の違いを見分ける爽快なゲーム
- **裏**：潜在的に色の見え方で困っている可能性のある人に、優しく医療機関への相談を促す
- お子さんが遊んだ場合は「大人の家族に内容を見てもらってください」という導線を用意しています

診断的な表現は一切使いません。

## 主な機能（v5.2）

- 15問の色見分けゲーム
- 連続正解コンボボーナス
- 通常・プロタン・デュータン・トリタンの簡易表示切替
- 色覚タイプを意識した色ペア生成（混同しやすい軸を優先）
- シミュレーション後の最低色差保証
- 強調体験モード
- キーボード操作対応
- 効果音ON／OFF
- ライト／ダークモード
- 終了時の家族導線（子供が遊んだ場合の配慮）

## 技術的な改善点（v5.2）

- ColorUtils クラスに色変換・生成ロジックを完全分離
- 状態管理とタイマー処理の整理
- 家族導線の表示タイミングを結果表示後に遅延させて自然に
- コードの重複削減と可読性向上

## 保存データ

テーマ設定だけを localStorage へ保存します。

- キー: `colorGameTheme`
- 値: `light` または `dark`

## テスト

```bash
node --check script.js
node --check theme-safety.js
node tests/static-check.cjs
```

## 色表示の限界

色変換行列と序盤ステージの色は、ブラウザ上で違いを簡易的に体験するための近似です。個人ごとの見え方を再現するものではなく、医療機器や標準化された色覚検査の代替ではありません。
